# SELO

Protocolo de comunicação entre agentes: extensão do A2A com criptografia de ponta a ponta nativa. A spec da v1 é a issue #1 do GitHub.

## Agent skills

### Issue tracker

Issues e specs vivem no GitHub Issues deste repositório (CLI `gh`). Veja `docs/agents/issue-tracker.md`.

### Triage labels

Vocabulário padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Veja `docs/agents/triage-labels.md`.

### Domain docs

Contexto único: um `CONTEXT.md` e `docs/adr/` na raiz. Veja `docs/agents/domain.md`.
